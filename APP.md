# UGC Ad Studio

## One-line product

Turn a product brief into a ready-to-shoot UGC ad pack: hooks, scripts, shot lists, storyboard frames, voiceover copy, and exportable briefs.

## Target users

- DTC founders
- media buyers
- creative strategists
- UGC creators
- small agencies serving ecommerce brands

## Problem

Ad ideation is messy.
Teams bounce between docs, chats, mood boards, and freelancers.
They need structured outputs they can hand to a creator or editor fast.

## Why this is worth paying for

- compresses creative strategy time
- creates consistent output format
- gives multiple usable variants, not one prompt output
- supports real team workflow and export

## Core workflow

1. User enters product, audience, tone, offer, angle, and constraints.
2. App generates hook matrix and angle options.
3. User picks or tweaks an angle.
4. App generates script variants and shot-by-shot breakdown.
5. App generates storyboard frames.
6. App generates voiceover copy / preview text.
7. User exports a creator brief.

## Pollinations role

- **Text:** hooks, scripts, CTAs, angle variations
- **Image:** storyboard frames, shot references, thumbnail concepts
- **Audio:** voiceover previews later in MVP / v1.1
- **Video:** rough animatic / concept reel later, not required for first MVP

## MVP scope

### Must-have

- brief intake form
- saved local session state
- hook matrix generator
- script generator
- shot list generator
- storyboard frame generator
- exportable creative brief page

### Nice-to-have after MVP

- brand memory / brand kit
- angle scoring
- voice preview generation
- multi-variant compare board
- client-ready PDF export
- rough video concept generation

## Non-goals for first MVP

- user accounts
- team collaboration
- payments
- automated deployment workflow
- advanced asset library backend

## Success metric for MVP

User can go from product brief to a usable creator brief in under 10 minutes.

## Risks

- outputs feel generic if prompt scaffolding is weak
- storyboard quality may vary heavily by product category
- too many options can create UX sprawl

## Product stance

This is not an image generator with a nicer UI.
This is a structured ad creation workstation.
